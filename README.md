# Crunchyroll 双语字幕

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Manifest V3](https://img.shields.io/badge/Chrome-Manifest%20V3-4285F4?logo=googlechrome&logoColor=white)](manifest.json)

一个 Chrome 扩展：把 Crunchyroll 播放器里选中的字幕（通常是英文）用大模型翻译成简体中文（也可改成其他目标语言），以**双语对照**显示。大模型失败时自动回退到谷歌免费机翻。

当前版本 [v0.3.0](../../releases/tag/v0.3.0) 支持原位翻译 ASS 字幕轨中的标题、招牌、角落注释和移动文字，并复用已有对白译文。

## 功能特点

- **双语对照**：译文与原文同屏显示，显示模式可在 双语 / 仅译文 / 仅原文 之间即时切换。
- **原位 ASS 字幕翻译**：对白、标题、招牌、角落注释和移动字幕中的可读文字都会进入翻译。普通对白按顶部或底部显示，定位字幕由 [ASS.js](https://github.com/weizhenye/ASS) 在原位置或沿原轨迹渲染。
- **自定义 ASS 对白样式**：底部居中的普通对白也能按对齐方式识别，支持字幕轨使用自定义样式名。
- **广告前导兼容**：识别广告播放信息，保留正片字幕状态；带广告时不执行开播暂停等待。同类播放结构提供 ASS 和可靠无字幕流时，可将正片硬字幕流切换为无字幕流。
- **本集字幕时间调整**：每集独立保存时间差，支持 ±600 秒、0.5 秒步进，即时调整且不重新翻译。
- **术语统一**：开播前先提取整集术语表，人名、地名等译法前后一致。
- **多供应商**：默认 DeepSeek，也支持任意 OpenAI 兼容接口（填 Base URL、API Key、模型名即可）。
- **可靠回退**：同一批翻译失败会重试一次，仍失败则改用谷歌机翻；都失败时，双语和仅原文模式可显示原文，仅译文模式不会回退显示原文。
- **本地缓存**：每集译文保存在本地，重看不会重复调用接口，也不重复花钱。
- **隐私**：API Key 只保存在本地，只发送到你配置的接口地址。

## 安装

本扩展目前通过“加载已解压的扩展程序”安装，尚未上架 Chrome 应用商店。

1. 从 [最新 Release](../../releases/latest) 下载 **Source code (zip)** 并解压，或直接克隆本仓库。
2. 打开 Chrome，地址栏输入 `chrome://extensions`。
3. 打开右上角的 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。
5. 点击扩展图标 → **设置**，填入 API Key，点 **测试连接**，成功后点 **保存**。

从 `main` 更新代码后，在 `chrome://extensions` 里点本扩展的刷新按钮，再刷新 Crunchyroll 页面。当前分支和已发布版本的变更见 [更新日志](CHANGELOG.md)。

## 使用

- 打开番剧播放页，在播放器里选择英文字幕即可。普通播放会暂停等待首批译文，最多等待 25 秒；检测到广告时不执行这段暂停等待。
- 正片播放信息到达后，若约 2.5 秒未收到选轨信号，会优先选择英文 ASS，否则选择其他 ASS 轨；播放器明确选择“无字幕”时保持关闭。
- 点扩展图标，在弹窗的 **字幕显示** 里切换 双语 / 仅译文 / 仅原文，立即生效（播放器上不放按钮，避免遮挡画面）。
- **仅译文** 模式在对应位置显示已有译文，等待翻译或翻译失败的行暂不显示。**双语**模式在定位字幕原处同时显示原文和译文，**仅原文**模式保留定位字幕的原始样式。
- 字幕与声音不同步时，在弹窗的 **本集字幕时间** 中拖动滑块、输入偏移秒数，或点击 **提前 0.5 秒 / 延后 0.5 秒**；**重置** 恢复 0 秒。正数延后，负数提前，范围 ±600 秒。例如带广告后字幕比声音早出现 30 秒，设置 **+30 秒**。调整立即生效，不重新翻译；保存成功后重看本集会恢复，其他剧集各自保存。
- 原文是两行的句子，译文也会按两行显示。
- 扩展弹窗显示翻译进度和谷歌兜底的句数，可以 **重翻谷歌部分** 或 **全部重翻**。
- 缓存可在设置页清空。

## 环境要求

- Google Chrome（或其他基于 Chromium 的浏览器，需支持 Manifest V3）。
- 一个 Crunchyroll 账号，且有权观看所选视频。
- 一个大模型 API Key（默认 DeepSeek），或任意 OpenAI 兼容接口。不填也能使用，此时只走谷歌机翻。
- 运行测试需要 [Node.js](https://nodejs.org/) 18 或更高版本。

## 工作原理

- 插件通过 fetch 和 XHR 拦截播放信息接口 `playback/v4/.../play`：旧版 `subtitles` / `hardSubs` 结构沿用干净流切换；新版 `stitchedElements` 结构收集正片外置字幕，并在本段有同语言 ASS 和唯一可靠无字幕地址时切换对应硬字幕流。混合结构分别处理顶层与各正片段；广告、预告等片段的 URL、时长和顺序保持原样。
- 下载 ASS 字幕后，同一翻译会话处理所有可读文字。插件自绘普通对白，ASS.js 使用原定位和时间区间渲染其他文字，纯矢量绘图不计入翻译进度。
- 无字幕的广告响应不会清空正片状态；重复响应中的 URL 签名变化不会重启翻译，换集或切轨后的旧异步结果不会覆盖当前字幕。
- 翻译：整集按 30 句一批，按播放位置优先；第一批与“术语表提取”同时发出，之后各批都带上术语表。
- 失败处理：同一批大模型重试 1 次，仍失败则改用谷歌；都失败时，双语和仅原文模式显示原文，仅译文模式暂不显示该句。
- 关闭插件（弹窗总开关）后需刷新页面，才会恢复 Crunchyroll 原来的字幕流。

### 目录结构

```
manifest.json          扩展清单（MV3）
src/
  background/sw.js     Service Worker，代理大模型与谷歌的网络请求
  page/hook.js         页面主世界脚本，拦截播放信息、识别字幕选轨
  core/                字幕解析、大模型、谷歌机翻、翻译调度、会话
  content/             双语字幕渲染（overlay）与内容脚本
  popup/               扩展弹窗
  options/             设置页
  shared/settings.js   设置读写
  lib/                 第三方库（ASS.js，MIT）
tests/                 单元测试（node:test）
docs/ai/               当前代码记忆与维护入口
docs/specs/            历史设计文档
```

## 更换模型 / 供应商

设置页选择 **自定义（OpenAI 兼容接口）**，填写：

- **Base URL**：请求地址为 `Base URL + /chat/completions`；
- **API Key**；
- **模型名**。

保存时 Chrome 会询问是否允许访问该域名。如果供应商需要额外参数（例如关闭思考模式），填在 **额外请求参数** 里，会合并进请求体，必须是 JSON 对象。

## 已知限制

- 只支持 ASS 字幕；配音版的 CC 字幕（VTT）暂不支持，会提示后跳过。
- 原位翻译读取 ASS 字幕轨中的文字。烧入视频像素的文字和纯矢量图形不在翻译范围内，当前版本没有 OCR。
- 新版 stitched 播放有可用无字幕轨时可切换；找不到可靠来源则保留原流，画面内烧录的硬字幕仍可能保留。兼容取决于播放结构及可用轨道，不保证覆盖所有广告类型或独立分段字幕。
- 依赖 Crunchyroll 当前的接口结构，网站改版后可能需要调整 `src/page/hook.js` 和 `src/core/playback.js`。
- 谷歌机翻为兜底方案，会把换行合并为空格，译文不分行。
- 目前只在 Chrome 上测试过。
